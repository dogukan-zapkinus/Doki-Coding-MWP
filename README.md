# Doki Coding — MWP

> **An interactive, free, and open-source way to learn the fundamentals of programming.**

Doki Coding is an educational project built around one simple idea:

**Learning to code should feel interactive, approachable, and rewarding.**

Instead of putting a beginner in front of a wall of documentation, Doki Coding turns the learning process into a guided path of small explanations, questions, coding challenges, and hands-on practice.

The project is being developed by **Muhammed Doğukan Cengiz** — and yes, I'm building it at **16 years old**.

That is a big part of what makes this project special to me: Doki Coding is not trying to be another complicated developer platform. It is an attempt to make the first steps into programming feel less intimidating and much more fun.

---

## What is Doki Coding?

Doki Coding is an interactive coding-learning platform focused on beginners.

The goal is to help someone go from:

**"I have never coded before."**

to:

**"I understand the basics, and I can write a small program myself."**

The learning experience is designed around short steps rather than huge lessons.

A typical learning path can include:

- simple explanations of programming concepts
- multiple-choice questions
- coding-focused challenges
- progressive lessons
- a visual learning roadmap
- immediate feedback
- local progress tracking
- a lightweight gamified experience

The project is intentionally designed to be easy to understand before it becomes technically demanding.

---

## Why does this project exist?

Programming can be incredibly powerful, but the beginning of the journey can also be unnecessarily confusing.

New learners often have to jump between:

- documentation
- tutorials
- videos
- code editors
- error messages
- different websites
- completely different teaching styles

Doki Coding tries to bring the first stage of that journey into one focused experience.

Instead of asking learners to understand everything at once, the platform introduces concepts progressively:

**learn → answer → practice → build**

The long-term goal is to make the first contact with programming feel less like studying a textbook and more like actually learning a skill.

## Current focus

The current MWP release focuses on creating a solid beginner experience rather than trying to support everything at once.

The active learning path currently focuses on **Python fundamentals**.

The platform is designed around a progressive roadmap where activities unlock as the learner completes previous ones.

The current experience includes:

- a 25-step Python learning path
- topic-learning activities
- practice questions
- progressive unlocking
- randomized answer placement
- a mini code editor
- local progress
- light and dark themes
- Turkish and English interface support
- interactive feedback
- sound feedback
- a fox-style learning companion
- a short onboarding flow

Other programming languages may appear in the interface before their full learning paths are ready. Those paths are intentionally kept locked until their content reaches the expected quality bar.

## The learning philosophy

Doki Coding follows a simple principle:

### Small steps beat overwhelming lessons.

A beginner should not have to understand variables, loops, functions, data structures, debugging, and software architecture in the first ten minutes.

Instead:

1. understand one idea
2. answer a question
3. try a related example
4. make a small mistake
5. think again
6. solve it
7. move forward

The project is designed around that loop.

---

## Why the fox?

Because learning does not have to feel cold.

Doki Coding uses a small fox companion to make feedback feel more human and memorable.

The fox can react to progress, encourage another attempt, and make mistakes feel like part of the learning process rather than a failure state.

The goal is not to copy another product.

The goal is to make Doki Coding feel recognizable as its own learning experience.

## Technology

The current MWP is intentionally lightweight.

The project can be built around standard web technologies such as:

- HTML
- CSS
- JavaScript
- browser local storage
- Web Audio APIs
- Devicon for language icons
- Google Fonts

The project is designed to work without requiring a backend for the basic learning experience.

That makes experimentation simple and keeps the first version accessible.

---

## Local-first approach

The current MWP can work without a server for core functionality.

Progress can be stored locally in the browser while the project evolves toward a more complete account and backend architecture.

This makes the project easy to run, test, modify, and experiment with.
