# Doki Coding - Learn Python Basics 🐍

Doki Coding is a serverless, interactive Python learning web application inspired by gamified learning mechanics.

## 🚀 Features
- **Serverless Architecture:** No backend or database required. User progress and language preferences are saved directly in the browser's `localStorage`.
- **Bilingual Support (EN/TR):** Instant UI language toggle between English and Turkish.
- **Progress Tracking:** Dynamic progress bar reflecting lesson completion state in real time.
- **Responsive Design:** Clean, mobile-friendly UI built with Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS (via CDN)
- **Hosting:** GitHub Pages
- **State Management:** Browser `localStorage`
